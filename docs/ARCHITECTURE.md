# Architecture

## Software-to-hardware flow

MNIST 28x28 image -> flatten row-by-row (784 values) -> FP32 Keras model ->
trained weights/biases -> INT8/INT32 quantization -> Python integer golden
model -> Verilog systolic MAC core -> bias/ReLU/requantization -> 10-way argmax.

Network: 784 -> 128 ReLU -> 128 ReLU -> 10 logits.

A hidden-layer size of 128 means the layer contains 128 independent Dense
neurons. Each neuron has one weight for every input element plus one bias.

## Numeric formats

- input: normalized FP32, then signed INT8 with scale 1/127
- weights: signed INT8, symmetric per-layer scale
- product: signed INT16
- accumulator: signed INT32
- bias: signed INT32 in accumulator units
- hidden activation: signed INT8 after ReLU/requantization
- final logits: signed INT32
- classification: argmax

The exact scales are generated by python/quantize_mnist.py and saved in
artifacts/quantization.json.

## 4x4 systolic array

There are 16 PEs. Activations enter from the left and move right. Weights
enter from the top and move down. Each PE registers both streams and adds one
signed INT8xINT8 product to a signed INT32 accumulator.

The array is reused for 784-element dot products and groups of output neurons.
A 784-element dot product therefore requires a multi-cycle schedule.

## Implementation boundary

The repository contains a synthesizable 4x4 arithmetic core, simple input and
weight memories, bias/ReLU/argmax primitives, a K-cycle controller, and a
top-level smoke-test integration.

The top-level RTL is a reference integration, not a finished
memory-bandwidth-optimized three-layer production NPU. Trained model files are
generated locally and are not fabricated or committed.

## Vivado

Reference: Vivado 2023.2, device xc7vx485tffg1157-1, Verilog only (.v).
Synthesis top: mnist_npu_top. Simulation top: mnist_npu_tb.
